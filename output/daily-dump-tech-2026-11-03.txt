CrowdStrike is spending nearly five hundred million dollars to acquire two artificial intelligence security firms, Fiddler AI and Dreadnode. Fiddler specializes in AI agent observability, providing deep-layer tracking for model hallucinations and data leakage, while Dreadnode focuses on automating security testing for large language models against adversarial prompt injection. The move follows increasing industry demand for tools to monitor and secure autonomous AI agents within corporate environments as these systems gain the ability to execute unauthorized code on internal enterprise networks. CrowdStrike aims to integrate these technologies directly into its Falcon platform to compete with standalone security vendors currently offering specialized AI oversight tools.

Apple is updating its App Store guidelines to mandate an eighteen-plus age rating for any dating apps or AI companion software that includes sexual or romantic content. The policy shift targets applications featuring synthetic characters designed for intimate interaction, requiring developers to implement rigorous age verification protocols that interface directly with government-issued identification databases. Apps failing to comply with these new age-gating requirements by the start of the next fiscal quarter face removal from the platform. This change marks a departure from previous store policies which allowed developers to self-certify content ratings without mandatory external age verification for AI-generated romantic scenarios.

Google has dismantled a botnet that was covertly running on one point three million Android TV boxes. The company terminated its relationship with the manufacturer responsible for the devices, which were being used as part of a distributed network for unauthorized traffic and proxy services. Forensic analysis by Google security researchers confirmed that the botnet software was embedded in the device firmware during the manufacturing process, allowing the attackers to bypass standard Android security permissions. These devices had been operating as high-bandwidth exit nodes for residential proxy networks, routing traffic for clients without the awareness of the original owners.

On the gaming front, Rockstar Games has finalized hardware requirements for Grand Theft Auto Six, with the title requiring up to two hundred twelve gigabytes of storage space. This installation size represents the largest single-game storage footprint in the history of the franchise, surpassing the previous entry by nearly one hundred gigabytes. PlayStation five users will also be required to update their console firmware to version fourteen point twenty-two to access the game, a move aimed at mitigating piracy and unauthorized system access by closing a specific hardware-level vulnerability identified by internal security audits. The update mandates a secure boot sequence that validates the game’s digital signature against the proprietary Rockstar server before allowing the software to load.

Microsoft is launching the Xbox Nano controller, a compact peripheral designed for smaller hands and portable usage. The device includes integrated Wi-Fi capability that allows it to connect directly to Xbox Cloud Gaming, effectively reducing input latency by bypassing the local console connection and communicating directly with server-side processing nodes. This bypass eliminates the standard Bluetooth or proprietary wireless handshaking delay associated with the current Series X and S wireless protocols. The controller also features updated haptic feedback motors that function independently of the primary game console, providing tactile response even when the user is playing on a tablet or web browser.

Finally, a working prototype of the abandoned Intel Larrabee graphics project has surfaced with restored functionality. Users recovered original development drivers to enable three-dimensional acceleration on the hardware, which Intel scrapped in two thousand ten before pivoting its graphics strategy toward the modern Arc architecture. The project was originally intended to be a many-core architecture based on the x86 instruction set, competing directly with high-end dedicated graphics cards from industry rivals. The recovered units are currently running specialized low-level APIs that allow the hardware to render basic three-dimensional geometries at native clock speeds, providing a rare glimpse into the internal architecture that preceded Intel's return to the discrete graphics market.
